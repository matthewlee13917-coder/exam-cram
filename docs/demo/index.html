EXAM-CRAM · DEMO

What your friend sees after cloning the repo

A real recording of the launcher, made on a Mac right after ./install.sh. Nothing is mocked up: the animation, the setup check and the questions are exactly what prints. Then the page their agent builds, using two demo courses.

STEP 1 · INSTALL, ONCE
# needs Node 18+, Python 3, and Claude Code or Codex signed in git clone https://github.com/matthewlee13917-coder/exam-cram.git ~/exam-cram cd ~/exam-cram && ./install.sh examcram

Step 2 · Run examcram

The book opens, its pages turn into 1s and 0s, and the bits settle into the notes list. Then it checks their setup and walks them through the questions.

~ — examcram

Answers typed in this run: auto-pull, Brightspace, check email, two exams. Recorded with --dry-run, so it stops where Claude Code would open. Without the flag, Claude Code (or Codex) starts in that folder with the instructions loaded.

Step 3 · Their agent takes over

Inside Claude Code or Codex, the skill runs these phases. The student only logs in, answers a couple of questions and waits.

GATHERPulls the files

Opens a visible browser on their course site. They log in themselves, and the agent downloads announcements, slides, practice exams and the syllabus. It never opens graded work.

SCOPEFinds what's on it

The professor's newest scope announcement decides what's IN and what's parked. Then it closes the browser.

BUILDWrites and checks

Builds a question bank modelled on real past exams and runs giveaway checks. Writes the cram sheet, mocks and videos, then builds the page from the shipped template.

VERIFYSecond opinion

A separate agent re-solves every question blind, and the page is checked at desktop and phone width. Then they get a link or a file.
